Featured project, October 2026

Job Hunt Tracker and Job Search Agent

Problem
Job hunting across many sites made it hard to see what was working.
What I built
A web app that logs every application with charts for replies, interviews and weekly targets, plus an agent that searches Reed and Adzuna, removes duplicates and scores each job against my skills.
How
HTML, CSS and JavaScript on GitHub Pages, a Supabase PostgreSQL database with secure sign-in and Row Level Security, and a serverless function that keeps the API keys secret.
