Personal project, October 2026

Job Hunt Tracker and Job Search Agent

I built the app I use to run my own job search. It logs every application, shows what is working, and searches Reed and Adzuna for jobs that match my skills.

Live and in daily use.

What it does

  • Tracks applications, feedback and outcomes, with charts for the funnel, weekly targets and the stage where applications stop.
  • Searches two job sites at once, removes duplicate adverts and scores each job against my skills.
  • Gives friends read-only access, which I approve. Only I can edit.

How I built it

  • HTML, CSS and JavaScript, hosted on GitHub Pages and installable on a phone.
  • Supabase PostgreSQL database with email sign-in and Row Level Security rules.
  • A serverless function that keeps the job site API keys secret.

    I'm analysing published survey data on how researchers use agentic AI, using NLP, pattern mining and clustering to group researchers by attitude and find what helps or blocks adoption.

  • Applied AI module
    2026

    Sentiment Classification of Customer Reviews

    I compared Naive Bayes, Logistic Regression, a simple RNN and an LSTM on Amazon kitchen product reviews, using TF-IDF and GloVe features in a reproducible Jupyter pipeline. I also found and fixed an embedding masking flaw that was holding the LSTM back.

    Best model: F1 score 0.830, ROC-AUC 0.921.

  • Big Data and Data Mining module
    2026

    UK Road Accident Data Mining and Forecasting

    I used SQL and Python on Department for Transport accident data to find patterns by hour, day, vehicle type and severity. I wrote the Apriori algorithm from scratch, clustered accidents around Hull with K-means, and forecast weekly and daily accident counts.

    Findings became road safety recommendations for Hull and the East Riding.
